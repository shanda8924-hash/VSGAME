# Equipment icon assets

VSGAMEの装備アイコンは、オリジナルのピクセルアートを個別透過PNGで管理します。
添付された参考画像の切り抜き・トレース・流用は行いません。

## 形式

- 完成サイズ: 64×64px
- 透過PNG、透明/不透明の二値アルファ
- 最近傍補間を使用し、アンチエイリアスを掛けない
- アイコン本体は最大54×54px内に収め、中央へ配置する
- Ground Glow、Loot Beam、パーティクルは画像へ焼き込まずGodot側で重ねる

## フォルダ

- `weapons/`: 武器10点
- `head/`: 頭装備3点
- `body/`: 胴装備3点
- `arms/`: 腕装備3点
- `legs/`: 脚装備3点
- `accessories/`: アクセサリー3点

命名規則は`<slot>_<type>_<rarity>_<連番3桁>.png`です。例:
`weapon_sword_uncommon_001.png`、`accessory_relic_mythic_001.png`。

## レアリティ別デザイン

5レアリティは同じ絵の色替えにせず、専用テンプレート・専用アイコンを持ちます。

- Uncommon(緑): 旅鉄の剣、旅人の短弓、革のスカウト帽、旅人の革服、斥候の手袋
- Rare(青): 月青の短剣、霜青の槍、蒼鋼の騎士兜、波紋の鎖帷子、風走りのブーツ
- Epic(紫): ルーン大剣、星術の杖、秘術師のローブ、魔紋の篭手、紫晶の指輪
- Legendary(橙): 太陽炎の戦斧、不死鳥の弩、獅子王の兜、竜爪の篭手、陽輪の護符
- Mythic(赤): 虚無の双爪、終焉の魔導書、虚空歩きの靴、星堕ちの脚甲、深淵の心核

実データとの対応は`data/equipment/templates.json`で管理します。ドロップ、所持一覧、
装備済みスロットは、装備インスタンスが保持する同じ`icon_path`を使用します。

## 地面表示

- 元画像は64×64pxのまま維持し、不透明画素範囲をプレイヤー本体の70〜100%（目標82%、
  最小24px、最大42px）へ正規化してワールド表示する
- 大きな四角背景、カード枠、上下浮遊、バウンド、巨大リングは使用しない
- アイコン真下だけに小型Ground Glowを置き、上方へ細いLoot Beamを伸ばす
- BeamはUncommon=緑28px、Rare=青36px、Epic=紫46px、Legendary=橙60px、Mythic=赤74px
- Legendaryは4粒、Mythicは7粒の控えめな局所パーティクルを重ねる

## 加工・検証

`tools/equipment_icon_pipeline.py`はクロマキー除去済み画像を外接矩形で切り出し、
最近傍補間で64×64pxへ正規化します。`validate`でサイズ、透明四隅、二値アルファを確認できます。
