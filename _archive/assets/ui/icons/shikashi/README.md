# Shikashi's Fantasy Icons Pack v2

`source/transparent_icons.png` contains all 284 non-empty 32x32 icons as the future candidate library.
`source/transparent_icons_drop_shadow.png` keeps the supplied shadow variant for later visual comparison.
The runtime uses only the extracted files under `items/` and `skills/`.

The original license and ordered icon catalog are preserved in `LICENSE_AND_CATALOG.txt`.
