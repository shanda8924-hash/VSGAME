# 再利用候補の棚卸しとロードマップ案（2026-11-12）

`_archive/` の中身を機能ごとに分け、新しい方向（横画面・自走式・1部屋=1戦闘・3×3盤面）での再利用の見込みを付けた。
判定は「そのまま＝ファイルを戻して参照を直すだけ」「改造＝考え方や一部を使い、書き直しが要る」「使えない＝前提が違う」。
盤面の中身・攻撃・属性・演出は未定なので、そこに踏み込む判定は「決めてから」と書いた。実装はしていない。

## 2. ロードマップ案（実装はしていない）

どの案も、各段でheadlessの検査を1〜2本足し、エラー・警告0件で進める。違いは「何を先に確かめるか」。

### 案A：盤面を先に（おすすめ）
このゲームの面白さの核は「回す・残す・揃う」なので、戦闘より先にそこだけを触れる形にする。
1. **盤面だけの試作**：3×3、回す、タップでホールド、8本のライン判定、揃ったときの演出。マスの中身は仮の記号5〜6種。戦闘なし。
2. **回す手触りの調整**：止まる順番、溜め、当たりの音と光。ここで「何度も回したくなるか」を判断する。
3. **自走式の戦闘の最小形**：主人公1人と敵1種が部屋で自動で殴り合い、勝敗が付く。
4. **つなぐ**：部屋クリア→回す→次の部屋。ラインの効果を仮に3種（例：攻撃が速くなる、HPが増える、追加の一撃）だけ戦闘へ接続。
5. **部屋の列とボス**：8部屋→ボス→結果。敵の役割を足す。
6. **中身を決めて増やす**：マスの種類、職業差、演出、音、保存。

- 良い点：核が面白くなければ早く分かる。戦闘を作り込む前に方向を直せる。
- 弱い点：戦闘とつながるまで「効果の嬉しさ」は測れない。

### 案B：戦闘を先に
1. **自走式の戦闘**：主人公と敵3〜4種（突撃・壁・弓兵・群れ）。退避した敵本体とAIを切り出して戻す。
2. **部屋の列とボス**：8部屋→ボス→結果。5分に収まる長さへ調整。
3. **盤面**：回す・ホールド・ライン。
4. **つなぐ**：ラインの効果を戦闘へ。
5. **中身を増やす**。

- 良い点：退避物を一番多く再利用でき、動く絵が早く出る。「見ているだけで5分もつか」を先に確かめられる。
- 弱い点：前回と同じく、戦闘を作り込んでから核の面白さを確かめる順番になる。

### 案C：縦切りの1周を最短で
1. **1周だけ通す**：戦闘（敵1種・数秒で終わる）→回す（マス3種・ライン判定だけ）→次の部屋→3部屋で結果。全部を最小で、見た目は仮。
2. **5分で遊んで判断**：どこが退屈か、どこが嬉しいかを実際の1周で見る。
3. **弱い所から厚くする**：盤面の手触り、戦闘の見応え、部屋数とボス、の順は遊んだ結果で決める。

- 良い点：全体のテンポ（時短・分かりやすさ）を最初から測れる。作りすぎない。
- 弱い点：どの部分も薄いので、最初の1周は面白く見えにくい。判断には想像力が要る。

### 先に決めておくと手戻りが減ること
- **部屋の見せ方**：上から見るか、横から見るか。pixelfxのエフェクトと、敵の配置の作りが変わる。
- **1回の戦闘の長さ**：8部屋＋ボスで5分なら、1部屋は20〜25秒、回すのは10秒前後が目安。
- **ラインの効果の持続**：次の1部屋だけか、盤面に残る限り続くか。ホールドの価値が変わる。
- **負けたらどうなるか**：即終了か、やり直しがあるか。
