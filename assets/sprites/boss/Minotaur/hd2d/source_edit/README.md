# 元画像の部品加工による薙ぎ払い

ユーザーの「元キャラクター画像を加工」の指定に基づく決定的な素材編集。
画像生成モデルはこの版には使用していません。元Aseprite/PNGは非破壊。

## 制作と接続

- `tools/export_minotaur_source_layers.py`: 元の`Minotaur.aseprite`からbody/fxを抽出。
  28コマのbody+fxと既存PNGのRGBA完全一致を毎回検証する。
- `tools/build_minotaur_source_motion.py`: 元Attack01のbody層8コマをそのまま使用。
  武器だけを回転せず、握り手・前腕・肩・胴のひねりを原画どおり連動させる。
  元の白いfx層だけを除外し、全コマのRGBA完全一致と上半身6ポーズ以上を検証する。
- `minotaur_cleave_side_8f.png`: 原画Attack01の全身薙ぎ払い。左向きは全身を反転。
- `minotaur_cleave_back_8f.png` / `minotaur_cleave_front_8f.png`: 同じ原画全身モーション。
  名称はワールド空間の三日月方向選択にのみ使用し、存在しない正面・背面像は新造しない。
- 3枚とも800×100 / 8コマ。`boss_attack_performance.gd`から試作のボスへ実接続。
- `provenance.json`: 原画SHA256、制作方法、制限。親フォルダのAI生成版は第二形態候補として保持、未接続。

## 制限

元データに正面/背面専用絵はないため、元の斜め向きの本体を保持する。
front/backは**床の剣撃方向の名称**であり、完全な正面/背面の新規原画ではない。
キャラクター側は原画Attack01の身体運動を優先し、武器だけが身体から離れて動く合成は禁止する。

ゲームの姿勢・床の銀白い刃・命中は同じ0.18秒の進行度に同期。
剣撃はユーザー参照の、中央が厚く両端が尖る白〜青白い三日月。細い直線に置き換えない。
青い扇全体の塗りは使わず、白い外縁と厚みのある青白い刃を描く。威力/半径は変更しない。
